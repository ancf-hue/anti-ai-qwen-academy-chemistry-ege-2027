# Анти-ии квен академия химия егэ-2027

Бесплатный социальный офлайн-проект — тренажёр ЕГЭ-2027 по химии по официальной демоверсии, спецификации и кодификатору ФИПИ.

> 🌐 **Онлайн-версия:** [ancf-hue.github.io/anti-ai-qwen-academy-chemistry-ege-2027](https://ancf-hue.github.io/anti-ai-qwen-academy-chemistry-ege-2027/)

## 📌 О проекте

Тренажёр работает в любом браузере без установки, без интернета и без регистрации. Все ответы проверяются локально — ваши данные никуда не отправляются. Поддерживается двуязычный интерфейс (RU / EN).

### Что внутри

- **34 задания**: 28 с кратким ответом (часть 1) и 6 с развёрнутым (часть 2)
- **56 первичных баллов**
- **210 минут** на выполнение
- Встроенный таймер экзамена с пресетами (210 / 60 / 30 минут)
- Чек-лист подготовки и подробный план на 25 дней
- Автопроверка части 1 (с учётом частичных баллов по спецификации ФИПИ)
- Честная самопроверка части 2 по официальным критериям ФИПИ
